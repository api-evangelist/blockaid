# Blockaid

> Blockaid is a web3 security platform that detects and responds to scams, fraud, financial risk, and smart-contract exploits in real time. Its API scans transactions, addresses, tokens, dApp sites, and messages across EVM chains, Solana, Bitcoin, Stellar, Sui, Starknet, Tron, and Hedera, returning a risk verdict that wallets, exchanges, and marketplaces (MetaMask, Coinbase, Uniswap, OpenSea) use to block malicious activity before it happens.

## Core scanning surface

- EVM: transaction, transaction-bulk, transaction-raw, json-rpc, user-operation, post-transaction, address, address-bulk scans
- Solana / Bitcoin / Stellar / Sui / Starknet / Tron / Hedera: transaction and address scans
- Chain-agnostic transaction scan
- Site (dApp URL) scan and report
- Token scan, token-bulk scan, token snapshots, recent rug-pull risks, token webhooks
- Address risk-exposure (compliance), enrichment / crypto fraud prevention
- Cosigner policy engine, platform assets, monitors, metrics, audit logs
